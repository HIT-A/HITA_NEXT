# HitaNEXT 使用手册（离线验收走查）

> 场景：DevEco 打开工程 → 编译通过（checklist A–E 销项）→ 模拟器/真机走查以下路径。
> 所有“离线”功能不依赖校园网络；网页登录、深圳课表/成绩真链路需真机回归（见文末）。
> 进入工程后先跑 `node scripts/static-checks.cjs` 确认静态三层自检 ALL OK。

## 0. 前置
1. DevEco Studio 5.0.x 打开 `C:\heyiwei\HitaNEXT`；按 SDK 调整 `compatibleSdkVersion`/`modelVersion` 后 Sync。
2. 签名：Project Structure → Signing Configs → 自动签名。
3. 工程已内置 HITA NEXT 风格化启动图标（`app_icon`/`startIcon`/`ic_launcher`）。

## 1. 首屏（Home · 3-Tab 主框架）
启动即 `pages/Home`，底部三 Tab：
- **今日**：今日事件列表（读 RDB，含演示数据后即有）；＋新建 / 完整时间线。
- **课表**：生成本地演示数据（确认弹窗）→ 周视图预览 / 科目管理。
- **我的**：会话摘要、成绩/考试/搜索入口、网页登录(EAS) / 会话管理备份 / 关于。
打开页面自动刷新各 Tab 摘要；无数据时先在「课表」Tab 点「生成本地演示数据」。

## 2. 今日时间线（TimeLinePage）
- 演示数据后即有今日/明日事件；类型徽标 + 状态徽标（已结束灰 / 进行中红 / 即将开始蓝 / 即将 15min）。
- 头部支持**日期翻看**（‹ 前一天 / 今天 / 后一天 ›，±30 天，含相对文案与星期）。
- 顶栏「＋」新建；点击条目 → 编辑（预填）；长按 → 编辑/删除（确认）；返回自动刷新。
- Home「时间线」Tab 同样支持条目点击直达编辑；空态一键生成演示数据。
- 考试类事件同时出现在「考试查询页」。

## 3. 课表周视图（TimetablePreview）
- 左右滑手势或按钮切周；08:00–24:00 真实分钟轴；圆角科目块；今日列遮罩。
- 「导出 ICS」→ 沙箱 `filesDir/hita-timetable.ics`，可导入系统日历核验。
- 导入 ICS：「更多 → 导入 ICS 课表」或课表管理页的文件图标 → 系统文件选择器选 `.ics` → 新建一张课表并设为当前。
  支持每周/每日重复（BYDAY/COUNT/UNTIL/INTERVAL）、EXDATE、单次改期；全天事件跳过；名称含“考试”的条目进入考试页。

## 4. 成绩 / 考试 / 搜索
- 成绩页：需教务会话，点击右上角「查询」拉取本学期成绩；未登录时空态引导去登录。
- 考试页：聚合本地全部课表中的考试事件，按时间升序展示；右上角「添加考试」录入考试安排。
- 本地搜索：教师/地点（本地事件聚合计数）。

## 5. 我的（ProfilePage）
- 三校区会话身份、退出、清除全部本地、**导出 JSON 备份 / 从备份恢复**。

## 6. 科目管理（SubjectsPage）
- 演示课表科目列表（学分/类型/课程次数）；色点轮换配色落库；删除科目级联删其课程事件。
- 课程类型（考试/考查）：本部/威海课表页不含考核方式，导入时补读执行计划 `/zxjh/queryZxkc` 与期末成绩
  `/cjcx/queryQmcj` 的“是否考试课”和学分；读不到时可在课表详情展开课程 →「课程类型」/「学分」手动修改。
