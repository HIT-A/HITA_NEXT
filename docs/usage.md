# HITA NEXT 使用说明

## 今日与时间表

- 今日显示日期、当天安排以及正在进行或即将开始的课程。
- 未添加课表时显示空态，不生成演示课程。
- 时间表以周视图展示课程，左右滑动切换周次，上下滚动查看其他时段。
- 点击时间表中的课程或考试，可以查看详细信息。

## 登录与导入

1. 进入「更多」，点击顶部教务会话卡片。
2. 选择校区，在学校统一身份认证网页中完成登录。
3. 返回「更多 → 导入课表」，确认学期、开始日期和节次时间后导入。
4. 已有日历文件时，可通过「导入 ICS 课表」导入。

登录和教务查询需要网络连接。已导入的课表保存在本地，可以离线查看。

## 课表管理

- 「最近课表」打开最近学期的课表详情。
- 「课表管理」可以选择已有课表、新建空课表、导入或删除课表。
- 课表详情支持调整开始日期、添加或编辑课程、删除课次，以及修改科目属性。
- 删除前请确认所选课表或课程，必要时先导出 ICS。

## 其他功能

- 考试：查看本地考试，手动添加、编辑和删除；教务查询取决于校区支持情况。
- 成绩管理：使用深圳教务会话查询成绩。
- 助手：根据本地课表回答课程安排问题；云端模型为可选设置。
- 资讯：查看校园资讯。
- 更多：课程提醒、公告和教务会话管理。
- 空教室：目前仅保留入口，尚未提供查询功能。
