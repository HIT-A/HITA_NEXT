# HITA NEXT 使用说明

## 今日与时间表

- 今日显示日期、当天安排以及正在进行或即将开始的课程。
- 未添加课表时显示空态，不生成演示课程。
- 时间表以周视图展示课程，左右滑动切换周次，上下滚动查看其他时段。
- 点击时间表中的课程或考试，可以查看详细信息。
- 时间表右上角调色盘调整标题、日期和时间刻度的文字颜色；课程详情右上角调色盘调整该课程所有周次的课块颜色。
- 调色面板支持彩虹色相条、直接点选或拖动颜色区域，以及快捷色。保存后生效并保存在本地；取消不修改原颜色。课块沿用亮色压暗规则，预览显示实际课块效果。

## 登录与导入

1. 进入「更多」，点击顶部教务会话卡片。
2. 选择校区，在学校统一身份认证网页中完成登录。
3. 返回「更多 → 导入课表」，确认学期、开始日期和节次时间后导入。
4. 已有日历文件时，可通过「导入 ICS 课表」导入。

登录和教务查询需要网络连接。已导入的课表保存在本地，可以离线查看。

## 课表管理

- 「最近课表」打开最近学期的课表详情。
- 「课表管理」可以选择已有课表、新建空课表、导入或删除课表。
- 课表详情支持调整开始日期、添加或编辑课程、删除课次，以及修改科目属性。
- 删除前请确认所选课表或课程，必要时先导出 ICS。

## 手动添加课程

- 在「时间表」右上角点击「＋」，或在「更多 → 最近课表／课表管理 → 课表详情」点击「添加课程」，使用同一套表单，保存到对应课表。返回时间表时保留原来查看的教学周。
- 添加页按「课程信息 → 上课时间 → 上课日期」填写。课程名称必填，教室和教师选填；底部显示缺项提示或预计课次数，必填内容有效后「添加课程」按钮才可用。
- 「单日」通过系统月历选择具体日期；「每周」可以同时选择多个星期几和多个教学周。例如周一、周三 × 第 2、3 周，会生成 4 个课次，使用相同的名称、地点、教师和起止时间。
- 教学周支持「全部／单周／双周／清空」。API 26 及以上使用 ArkUI Grid 原生滑动多选，也可逐个点选；API 23～25 保留逐个点选和快捷选择。滑动经过周数可连续选中或取消，不滚动外层表单。
- 教学周旁显示起算日期和当前课表总周数，按目标课表的开学日期计算，可点击「增加 5 周」继续选择；保存前至少选择一个星期和一个教学周。新增课次超出原结束日期时，会提示并将课表延长至最后课次所在周的周日，范围更新与课次一起保存。单日早于开学日期时不能保存，避免改变既有教学周编号。
- 上课时间可选「按节次」或「具体时间」；节次使用当前课表自己的作息，显示对应起止时刻。切换模式保留各自的选择，保存时只使用当前模式。
- 点击「选择已有课程」可带入名称、教室和教师，并沿用所选科目的颜色与关联；教室、教师仍可修改。点击「手动填写」退出已有课程选择。没有课次的科目也可以选择。
- 一次添加的多个课次一起保存，失败不会留下部分课次。已有同名科目会继续使用其颜色和属性；编辑已有课次仍只修改该课次，不会批量改动同名课程。

## 导出至手机日历

- 在「更多 → 课表工具 → 导出至手机日历」导出当前正在显示的课表。
- 首次导出需要允许日历读写权限。拒绝后可在系统设置的 HITA 权限中开启，再次点击导出。
- 系统日历中会出现「HITA · 课表名称」，包含该课表全部课程、考试及其他有效日程的实际日期、时间、地点和教师信息。
- 重复导出会更新已有日程，并移除该课表中已取消或改期的旧导出日程。课表变化后需要再次点击导出，不会自动同步。
- 导出中途失败可以重试，已写入的课次不会重复添加。空课表不会清空之前导出的日历。
- 在 HITA 中删除课表不会删除系统日历中的副本；可在系统日历中单独管理。

## 其他功能

- 考试：查看本地考试，手动添加、编辑和删除；支持本部、威海本科教务查询及原有深圳查询。
- 成绩管理：使用深圳教务会话查询成绩。
- 助手：根据本地课表回答课程安排问题；云端模型为可选设置。
- 资讯：博客订阅 HOA；通知按最近一次登录时选择的校区加载，深圳为深圳信息网、本部为今日哈工大、威海为今日哈工大（威海）。未登录时默认显示本部通知，刷新会重新读取校区；各校区均从最新一页开始加载。若通知网站要求认证，可点“打开通知网站”，完成认证后返回重试。
- 更多：课程提醒、公告和教务会话管理。
- 空教室：按教学楼、学期和周次自动查询三校区本科教务记录，点击教室查看每天各节占用。

## 考试查询

1. 在「更多」的教务会话入口登录所需校区，再进入「考试查询」，点击右上角「查询」。
2. 使用最近登录的校区会话。本部、威海优先读取考试页面选中的学期，分别查询期末、期中与补考，结果显示校区和学期。
3. 点击教务考试查看课程名称、日期、起止时间、考场和考试类型；点击「导入到课表」保存至当前课表，之后可在时间表和考试列表查看、编辑或删除。
4. 未公布日期或完整起止时间的考试仍会显示，但不能直接导入，避免生成错误时间。可以通过右上角「添加」手动补充。
5. 部分类型查询失败会明确提示，不会当作“没有考试”。会话过期时需重新登录；研究生考试接口尚未接入本部、威海。

本部、威海实现参考安卓与 iOS 的本科教务接口，真实账号的查询结果仍需按学校实际发布内容核对。

## 空教室查询

1. 在「更多」顶部教务会话卡片中登录所需校区，再进入「空教室」。查询使用应用当前选用的教务账号，支持本部、威海、深圳本科教务。
2. 顶部横条从左到右为教学楼、学期、周次。进入页面、变更任一选择后自动查询，无需另点查询按钮。周次选择范围与安卓 3.0.0 一致，为第 1～20 周。
3. 初次进入选当前学期、第一栋教学楼。周次取对应校区已导入课表的当前周；没有对应课表时选第 1 周。右上角刷新会重新加载选项和结果。
4. 教室以双列卡片显示「空闲／被占／将占／未知」。与安卓一致，状态按**所选周的占用表**，结合今天的星期和当前节次判断；查看其他周时不能把卡片当成实时现场状态。
5. 点教室打开底部详情，默认选今天，可切换周一至周日，逐节查看时间及「空／占用／未知」。星期切换直接使用已查询的整周数据。

有历史查询时先显示缓存，再更新网络数据；缓存标明保存时间，更新失败时保留提示。初次加载学期和教学楼仍需要网络。空闲只表示教务系统未登记占用，不保证教室实际开放。

没有登录或会话失效时可以进入教务账号页面，登录后返回重试。其他加载错误同样提供重试和教务账号入口。深圳未获取到实际节次时间时，卡片显示未知，详情提示刷新；不会套用其他校区时间。本部研究生接口尚未接入。


教务导入的教学周范围按实际课次确定（例如最后一节课在第 17 周，则默认到第 17 周），不再固定为至少 25 周。旧版导入且仍保留默认 25 周结束时间的课表，会按已有课程和日程修正范围；手动指定的其他范围不变。
