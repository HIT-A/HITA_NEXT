# HITA NEXT 0.4.0

更新日期：2026-10-23

本说明汇总从 0.3.2（[e675234](https://github.com/samerberry/HITA_NEXT/commit/e675234)）到 0.4.0 的累计更新。

## 今日

- 重新设计今日页：问候语、日期与教学周标签，主卡片按“上课中 / 下一节 / 已下课”显示倒计时、地点与进度，课都上完后预告明天的第一节课。
- 14 天内有考试时显示考试提醒卡片，点击进入考试页。
- 今日安排的每节课左侧显示与时间表一致的课程色条，已结束的课程淡化显示。

## 时间表与桌面卡片

- 时间表支持视频背景；课程编辑手势与交互进一步简化。
- 桌面服务卡片显示当前课程进度，并可自定义背景。
- 修复使用非教务导入的课表时，桌面卡片读取原课表、进入应用后时间表切回原课表的问题。
- 后台静默续期教务会话，并在更新课表时与已有课表合并。

## 教务

- 修复本部实验课无法导入：通过实验管理桥接获取会话，并修正单点登录 Cookie 与课表解析。
- 考试、成绩管理、学分查询、空教室与导入课表改为从“更多”以底部弹层打开。
- 课程提醒支持自定义提醒时间。

## 资讯

- 博客与通知改为消息列表排版：左侧来源头像，标题与语义化日期（今天、昨天、N天前），其下为分类标签与发布来源；博客显示摘要。
- 通知标题开头的【分类】与“转发”标记提取为标签，并去除重复的学校名称前缀。

## 更多

- 调整分组顺序为：课表工具、教务功能、设置、更多；“公告”移入“更多”。
- 新增“关于”页：应用信息、制作者与鸣谢，并提供隐私政策。隐私政策与[华为协议托管服务上的版本](https://agreement-drcn.hispace.dbankcloud.cn/index.html?lang=zh&agreementId=2056866492535841728)一致。

## 兼容性

- 最低系统版本仍为 HarmonyOS 6.1.0（API 23）。
