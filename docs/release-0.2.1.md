# HITA NEXT 0.2.1

更新日期：2026-10-10

本次更新新增空教室查询，并改进时间表与课程颜色设置。

## 新增

### 空教室查询

- 从「更多 → 空教室」进入，按教学楼、学期和教学周查询教室占用情况。
- 切换查询条件后自动更新，使用双列教室卡片展示空闲、被占、将占或未知状态。
- 点击教室可查看周一至周日各节课的时间及占用情况。
- 支持查询结果本地缓存；更新失败时显示缓存时间和错误提示。
- 已接入本部、威海、深圳的本科教务查询逻辑；深圳已完成模拟器实际会话运行检查，本部、威海仍待对应账号验收。

### 自由调色

- 时间表右上角调色盘支持自选标题、日期和时间刻度的文字颜色。
- 课程详情右上角新增调色盘，一次修改应用到这门课程所有周次的课块，不影响其他课程，也不会跳转当前周次。
- 两个入口均支持彩虹色相条、直接点选或拖动的颜色面板、快捷色和实时预览。
- 保存后在本地保留颜色，取消不改变原设置。课块保留过亮颜色自动压暗的处理，以预览效果为准。

## 修复

- 修复上下拖动调色选点时带动底部弹窗的问题。
- 修复调色选点周围出现方形阴影的问题。
- 修复调色弹窗关闭过程中快速操作可能重复打开，以及迟到的保存回调可能误关后续弹窗的问题。
- 修复空教室详情滚动条与「空／占用」状态重叠的问题。
- 修复空教室切换星期、查询条件或缓存更新后，部分文字和结果未及时刷新的问题。

## 测试与使用说明

- 本次功能已通过 296 项自动回归测试、项目静态检查及 ArkTS 构建；调色交互和深圳空教室查询已在 HarmonyOS 7 / API 26 模拟器检查。
- 本部、威海实际账号、浅色模式、大字体及真机／API 23 设备尚待补验。教室占用信息请以学校教务系统为准。
- 本地生成的 debug HAP 使用调试签名，可能仅适用于签名 Profile 中登记的设备，不作为应用商店发布包。
- 工程版本为 `0.2.1`，内部版本号为 `2000004`；本次不调整最低系统版本。
