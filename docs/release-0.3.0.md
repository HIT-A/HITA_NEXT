# HITA NEXT 0.3.0

更新日期：2026-10-13

本说明汇总从上次 0.2.1 到本次 0.3.0 的累计更新，包括中间开发版本的功能和界面调整。对照范围为 [0.2.1 发布提交 74c3aae](https://github.com/samerberry/HITA_NEXT/commit/74c3aae) 至 [0.3.0 构建源码 6cf3738](https://github.com/samerberry/HITA_NEXT/commit/6cf3738)。

## 界面与交互

- 新增沉浸材质、触摸光效及渐变模糊，覆盖今日安排卡片、时间表课块、顶部工具栏、底部导航、分段按钮及部分编辑控件；具体效果依系统版本和设备能力启用。
- 优化资讯页的悬浮分段栏、内容滚动和顶部过渡，以及底部导航点击、长按滑动选择与释放反馈。
- 统一教务账号、网页登录、课程详情、调色盘、考试、空教室等底部弹层的顶部留白，改善标题与面板边缘的距离。
- 优化课块触摸反馈、重叠课块的点击定位和教室名称滚动；改善课程颜色实时预览、选色控件及弹层开关行为。

## 添加课程与教学周

- 时间表右上角新增「＋」入口，与「更多 → 最近课表／课表管理」里的添加课程共用表单，保存到对应课表。
- 支持单日日历选日期；每周模式可同时选择多个星期几和教学周，并提供全部、单周、双周、清空及滑动连续多选。滑动多选需 API 26 及以上，较低版本保留点击和快捷选择。
- 上课时间支持按节次或填写具体时间，节次使用当前课表保存的作息；可选择已有课程带入名称、教师、教室和颜色。
- 教学周范围按课表起止日期及实际导入课次确定，修正旧版导入时固定为 25 周的默认范围；显示教学周起算提示，周数格子末尾的「＋」每次扩展 5 周。
- 新增课次超出原结束日期时提示延长课表。批量课次一起保存，减少保存失败后只留下部分课次的情况。

## 时间表与课程管理

- 查看其他教学周时新增「回到本周」按钮；今天不在该课表范围内时不显示。
- 当前查看的周有 18:30 及以后开始的课程时，右下角显示下箭头；点击滚动至课表底部，接近底部后隐藏。
- 课程详情新增「翘课」操作，经确认后移除当前课块对应的本地课次；课表详情支持左滑课程并确认删除整门课程及其全部课次。
- 课程移除增加粒子消散动效，并更新本地今日安排与提醒。这些操作只修改 HITA 本地课表，不改变学校教务平台的选课记录。

## 考试与成绩

- 在原有深圳考试查询基础上，新增本部、威海本科期末、期中和补考查询，展示查询校区、学期及考试详情。
- 已公布完整日期与时间的教务考试可导入当前课表；时间未完整公布时保留原信息，不生成默认考试时间。
- 新增考试独立调色，颜色只应用于对应考试；完善考试详情、编辑与查询错误提示。
- 在原有深圳成绩查询基础上，新增本部、威海本科成绩查询，并完善三校区的学期和成绩类型选择、课程详情及统计展示。
- 官方统计与当前列表的本地统计分开展示并注明范围；GPA、排名等缺失字段不自行推算，等级制成绩不直接换算百分制。

本部、威海研究生的考试及成绩接口尚未接入，相关本科查询仍需更多真实账号反馈。

## 校园资讯与教务状态

- 校园通知按最近登录的校区加载对应官方来源：深圳信息网、今日哈工大、今日哈工大（威海）；完善首次加载、刷新、分页和需要认证时的网站入口。
- 实际成绩、考试、空教室或课表请求明确返回登录失效后，「更多」显示「已过期教务」及红底图标；状态按校区保存在本地，重新登录成功后恢复。
- 进入「更多」及打开账号弹层只读取已保存状态，不额外检查连接；网络超时和普通服务故障不会直接标为过期，旧请求的延迟结果不会覆盖新登录状态。

## 测试重点与兼容性

- 对照学校平台核对三校区本科考试、成绩、统计范围和校园通知，重点收集本部、威海真实账号结果。
- 核对不同课表的节次作息、教学周范围、多日期批量添加、返回本周及晚间课程快捷入口。
- 检查教务过期提示、重新登录恢复、颜色保存、课程移除以及弹层滚动和关闭。
- 继续收集真机、API 23、大字体与浅色模式反馈；沉浸效果及新控件按系统能力启用，最低系统保持 HarmonyOS 6.1.0（API 23）。
- 课程、考试、成绩及教室使用情况以学校官方信息为准。

## AGC 测试版更新说明

0.3.0 更新说明（相较 0.2.1）

1. 界面升级：新增沉浸材质、触摸光效与渐变模糊，统一卡片、导航和底部弹层体验。
2. 添加课程：时间表新增入口，与课表管理互通；支持单日日历、多星期／教学周、单双周与滑动多选，沿用当前课表作息。
3. 教学周：按实际课次确定范围，末尾「＋」扩展 5 周；新增返回当前周及晚间课程下箭头。
4. 课程管理：新增「翘课」移除本地课次、左滑删除整门课程及粒子动效，不改变学校选课。
5. 考试：新增本部、威海本科期末／期中／补考查询，支持导入课表及独立调色。
6. 成绩：新增本部、威海本科查询，完善深圳查询，支持学期／类型筛选、详情及官方／本地统计。
7. 资讯：按校区加载官方通知，完善分页和认证入口。
8. 教务：失效后显示「已过期教务」和红底图标，重登恢复；进入「更多」不主动检查。
9. 修复：优化课块点击、教室文字滚动、导航手势和颜色预览。

沉浸效果与滑动多选依系统支持。重要课程、考试与成绩信息以学校官方系统为准。

详细操作见[使用说明](usage.md)，后续修改遵循[项目约定](../AGENTS.md)。
