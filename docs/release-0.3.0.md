# HITA NEXT 0.3.0

更新日期：2026-10-13

本次测试版完善成绩查询与统计、时间表快捷操作，以及教务登录状态和底部弹层体验。

## 新增与改进

- 成绩查询与统计：接入本部、威海、深圳本科成绩查询，支持切换学期和成绩类型；区分教务官方统计与当前列表的本地统计，缺失的 GPA、排名等字段不自行推算。本部、威海研究生成绩接口尚未接入。
- 时间表快捷操作：查看其他教学周时可返回当前周；查看周有晚间课程时，右下角显示下箭头，可快速滚动到课表底部。
- 添加课程：支持单日或每周安排，星期几和教学周可多选；教学周末尾的「＋」每次增加 5 周，节次沿用当前课表的作息。
- 教务状态：实际查询明确返回登录失效后，「更多」显示「已过期教务」及红底图标；重新登录成功后恢复。进入「更多」及打开账号弹层只读取本地状态，网络超时不会直接标为过期。
- 弹层布局：统一教务账号、网页登录、课程详情、调色盘、考试、空教室等底部弹层的顶部留白。

## 测试重点

- 三校区分别核对成绩列表、学期和成绩类型，以及统计范围是否与学校教务平台一致。本部、威海真实账号仍需继续验收。
- 核对教学周与当前课表的起止日期、添加课程使用的校区作息，及晚间课程下箭头的位置和跳转。
- 会话失效后核对「已过期教务」提示与重新登录后的恢复；断网不应被直接标成过期。
- 检查弹层标题留白、滚动、关闭及表单可用性，继续收集 API 23 真机、大字体和浅色模式反馈。

## 构建与验证

- 版本名称：`0.3.0`；内部版本号：`3000000`。
- 最低系统版本保持 HarmonyOS 6.1.0（API 23）。
