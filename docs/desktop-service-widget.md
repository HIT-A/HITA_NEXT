# 桌面服务卡片

HITA NEXT 提供“下一节课”桌面服务卡片。卡片从当前本地课表读取下一节未来课程，显示开始倒计时、课程地点和授课教师；不发起教务网络请求，也不会把账号或会话信息写入卡片。

添加方式：

1. 打开 HITA NEXT，在“更多”页面的“课表工具”中点击“桌面服务卡片”。
2. 在系统服务卡片管理页选择 HITA NEXT，添加到桌面。

也可以长按桌面上的 HITA NEXT 图标，选择“服务卡片”。系统支持 2×2 和 2×4 两种尺寸；2×2 显示紧凑信息，2×4 会并排显示倒计时和课程详情。

卡片中的时间使用本地设备时间。卡片在应用退出后仍会根据缓存的课程时间继续倒计时，并在课程开始后自动切换到下一节缓存课程。导入、编辑、删除课程或切换当前课表后，应用会主动刷新已发布的卡片；系统定时更新周期仍由 HarmonyOS 服务卡片调度策略决定。
